# 제뉴인학원 앱

학생 PWA와 관리자 대시보드, 학부모 리포트 프로토타입을 하나의 Vite 프로젝트로 실행합니다.

## 실행

```bash
npm install
npm run dev
```

- 학생 앱: `http://localhost:5173/`
- 관리자 대시보드: `http://localhost:5173/admin`
- 학부모 리포트: `http://localhost:5173/report?key=demo`

## 데모 계정

- 승인 계정: `민지` / `010-0000-0000`
- 승인 대기 계정: `박준서` / `010-1234-5603`
- 이용 종료 계정: `오지훈` / `010-1234-5607`

로그인 상태는 브라우저 `localStorage`에 저장됩니다. 로그아웃하면 다른 상태를 확인할 수 있습니다.

## 현재 범위

기존 화면 프로토타입을 실행 가능한 React 앱으로 연결하고, 학생 상태별 접근 차단, 관리자 회원/출석/콘텐츠/공지 화면, 학부모 리포트, 로컬 QR 생성, PWA 메타데이터를 포함합니다.

실서비스 전환 시에는 `demoAccounts`와 프로토타입 내부 seed state를 Supabase Auth/DB/Storage API로 교체해야 합니다. 특히 학생의 `status`는 앱 진입 및 API 요청 때 서버에서 다시 조회하고, 제출 완료 숙제는 DB 정책과 서버 API에서도 수정/재제출을 거부해야 합니다. `service_role` 키는 브라우저 코드에 넣지 않습니다.
